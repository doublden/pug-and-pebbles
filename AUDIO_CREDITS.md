# Sound credits / Источники звуков

The recordings below are normalized, faded and converted to 22.05 kHz mono WAV. Pitch/playback speed varies in game. These audio adaptations retain their listed licenses; the game code is separate.

Записи нормализованы, обработаны плавным началом/концом и преобразованы в моно WAV 22,05 кГц. В игре меняется скорость воспроизведения. Лицензии относятся к этим звуковым файлам и их обработке.

- `sounds/sneeze.wav`: **Neo139**, [Sneeze.ogg](https://commons.wikimedia.org/wiki/File:Sneeze.ogg), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
- `sounds/fart.wav`: **El Charpi**, [Fart.ogg](https://commons.wikimedia.org/wiki/File:Fart.ogg), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Modified file distributed under the same license.
- `sounds/snort.wav`: **Secretlondon**, [Mudchute pig 2.ogg](https://commons.wikimedia.org/wiki/File:Mudchute_pig_2.ogg), [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). Modified file distributed under the same license. This is a natural pig oink used as the pug's comic snort.

Other effects and music are generated in-game with Web Audio. / Остальные эффекты и музыка создаются в игре средствами Web Audio.
